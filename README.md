# sportbox

Чтобы добавить трансляцию, задайте переменную окружения `ADMIN_PASSWORD` на сервере чата. Откройте раздел «Для администратора: добавить трансляцию» на сайте и укажите название, ссылку на поток и пароль.

Опубликованная трансляция хранится только в памяти сервера: её видят подключённые зрители, и она показывается новым зрителям, пока сервер работает. После перезапуска сервера её нужно опубликовать заново.

В чате отображаются подключённые пользователи и есть кнопки футбольных эмодзи. Список онлайн хранится только в памяти сервера и очищается при отключении пользователей или перезапуске.
